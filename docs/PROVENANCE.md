# Provenance

The project was created on 2026-10-05. Source, logo, synthetic cover artwork, wallpaper, and promotional layout were newly authored for Lilt. The code and authored assets are under MIT; third-party software retains its own license.

AI tools assisted implementation, testing, documentation, and draft promotion. A maintainer should inspect and understand all code before publishing a stable release or submitting it for GNOME review. Current GNOME review rules distinguish assistance from extensions generated without a maintainer able to explain their implementation. This project does not claim acceptance.
